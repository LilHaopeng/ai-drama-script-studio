# 短剧人物命名、剧名红线与分集命名规范（精炼版）

在 `bible`（定剧名与 `@CHAR-*` 固定班底）、`outline`（排 `01_分集卡点纲.md`）与 `script`（定 `第001集 集名` 与龙套称呼）阶段读取。短剧核心角色仅 3–8 人且全员配音口播，命名直接决定活人感与听觉辨识度。

---

## 一、人物命名五项铁律与小班底配额

### 1. 五项防 AI 味铁律
1. **24 字高频意象限流池（限流非封杀）**：`清、晏、舟、川、微、晚、辞、烬、寒、墨、渊、衡、溯、栖、疏、尘、妄、诀、凛、昭、昀、屿、汐、言`。现代/年代/科幻 3–8 人班底累计命中 **≤ 1–2 次**；武侠仙侠 **≤ 2–3 次**。
2. **禁双重套路叠加**：严禁“低频文艺姓（沈/顾/陆/裴/谢/傅/晏/萧/祁/岑/郁/温）+ 高频意象字”拼装（回避沈清晏、顾见微、陆星移、谢惊寒）。允许“文艺姓+朴素名”（沈涛）或“大姓+雅致名”（张清晏）。
3. **父母/时代视角反剧透**：姓名反映出生年代、地域与家庭文化，禁功能贴标签（冷酷带寒、复仇带烬、反派带阴鸷字），鼓励姓名与性格反差。
4. **龙套降噪**：辨识度留给核心 3–8 人；过场路人、房东、保安、掌柜一律用常见大姓或社会称呼（老陈、王师傅、红姐、赵婆子），禁给龙套配文艺全名。
5. **同框防撞与 TTS/配音防同音**：高频同框或同阵营角色严禁同姓扎堆、尾字同音、声调雷同或字形相近（如严禁同剧并存“林风/林峰”“陈欢/程焕”），确保口播与竖屏字幕瞬间分辨。

### 2. 题材小班底实操配额（替代难心算百分比）
- **现代都市 / 悬疑 / 职场 / 科幻**：绝大多数取常见/中频姓（王李张刘陈杨黄赵周吴徐孙高林郑梁宋唐许韩曹程等），**低频文艺姓整班底 ≤ 0–1 个**；锚定出生年代与城乡背景（科幻冷峻感留给工号/呼号）。
- **民国 / 年代**：遵循地方宗族大姓；民国世家重字辈表字、底层偏排行/乳名；改开前后重务实寓意与大小名分离，忌全员“建国/翠花/铁柱”。
- **古代历史 / 权谋**：高门望族可提高传统望姓权重并守字辈避讳；寒门官吏用务实名；平民仆役用大姓+排行/粗名（赵大郎、陈阿四）；分清名/字/行第/官称。
- **武侠 / 仙侠**：常见大姓与江湖常规姓为主，生僻/复姓单季 **≤ 1 族**（绑定宗门血脉）；分清俗名/道号/绰号，多取器物草木，忌全员“寒墨渊烬夜影殇”。
- **西幻 / 异世界**：高频译制 AI 名（艾莉丝、艾莉娅、莉莉丝、亚瑟、莱昂、凯尔、卢修斯、塞巴斯蒂安、维克多、奥利维亚、克莱尔等）全班底 **≤ 0–1 个**，按区域固定音系并区分贵族名号与平民单名。

### 3. 输出前 4 问自检
1. 3–8 人班底低频文艺姓是否超标？有无“文艺姓+意象字”双重拼装？
2. 龙套是否已降噪为社会称呼？
3. 全员姓名连读一遍：TTS 口播是否零同音/近音撞车？
4. 是否经得起追问：“父母在那个年代与阶层真的会起这个名吗？”

## 二、剧名红线、书名熔断铁律与异构 3 备选

### 1. 红果与短剧平台硬审核红线
- **长度**：**≤ 20 字符**；
- **禁符号**：严禁含 `《》<>【】[]` 与空格（红果/抖音/封面剧名完全一致）；
- **禁夸张营销词**：严禁夹带 `爆款`、`绝密`、`最强`、`第一`、`逆天`、`秒杀`、`热播`（`export_drama.py` 自动提示）。

### 2. 五大剧名型谱与「书名熔断铁律 & 异构 3 备选」
| 型谱 | 长度 | 气质与示例 |
|---|---|---|
| **1. 意象/地标/器物短名** | 2–5 字 | 具象场地或物件：夜自习守则 / 旧巷修车铺 / 金缮 |
| **2. 概念/反差短语** | 4–8 字 | 规则错位或强反差：借来的嫁衣 / 替身不上班 / 规则别超纲 |
| **3. 人物/职业锚点** | 3–7 字 | 手艺或人设标签：南城补瓷人 / 胡同修理工 / 金牌背锅侠 |
| **4. 半句对白/悬念截断** | 6–12 字 | 情绪张力半句话不剧透：三分钟，修好这台机 / 这桌席我不坐了 |
| **5. 信息流强钩子** | 10–18 字 | 下沉测投按需选用；**限流**机械复读“XX后，全家悔疯了/跪求原谅”单一复句 |

**书名熔断铁律 & 异构备选**：严禁拿“一句话选题梗概”直接当正式剧名；立项必跨型谱出 **3 个异构备选剧名**（绝不连给 3 个同款长句）。

## 三、分集名（`第001集 集名`）规范与四项熔断

- **三种合法体制**：
  1. **画面锚点型（`2–6 字`，推荐 `ai-drama` / `comic-drama`）**：抓核心物件、动作或数字（`第001集 坏录像机`、`第002集 三分钟`、`第003集 沾泥黑皮鞋`）；
  2. **短对白/悬念切片型（`4–8 字`，适合 `shadiao` / 强交锋剧）**：抓包袱切口或半句狠话不揭底（`第001集 不准抬头`、`第002集 这题超纲了`）；
  3. **纯集数无副标题（`第001集`）**：直传连播剧直接采用。
- **四项熔断清单**：① 严禁把分集梗概塞进集名（推进摘要放集头 `- 本集爽点/推进：`）；② 限流 `A与B` / `XX的YY` 排比（整季 ≤20%，禁连撞）；③ 限流空泛词（`危机降临/暗流涌动/真相大白/终极对决`）；④ 每 10 集竖扫目录自检。
