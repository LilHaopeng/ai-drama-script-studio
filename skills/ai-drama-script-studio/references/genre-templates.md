# 三大剧种特化剧本规范与商业红线（权威主规范）

在 `bible`（定调）与 `script`（写分集剧本）阶段读取。本文件为三大剧种写法、红果 40× 分成旁白红线与 MiniMax-H3 表演/台词规范的**唯一权威来源**。

---

## 剧种 1：`ai-drama`（常规仿真人 / 写实 AI 短剧 · 默认后端 `minimax-h3`）

适配红果「AI 剧」热播赛道（年代穿越创业、乡土/美食手艺、历史团队、都市轻逆袭/萌宝），深度对齐 **MiniMax-H3（Hailuo 3）** 原生影音特性：

### 1. MiniMax-H3 镜头与口型对白规范
- **善用 5–15 秒原生音画同步长单镜**：一集 60–90 秒拆为 **8–14 个连贯音画镜**（每镜 5–12 秒），单镜内可演完“短对白 + 对手微表情变脸 + 回怼”，表演连贯性远胜强行切碎的哑巴短镜。
- **自然口型短对白**：单镜内角色开口中文台词建议 **12–35 字**（上限 ≤38 字），念得从容、口型稳且竖屏字幕不挡脸；超长信息拆成正反打双镜，或用物件特写/对方反应镜配画外角色对白过渡。
- **多人同框口型隔离铁律**：单镜同时出现 ≥2 名有台词同框角色时，画面描述里**必须显式写明「谁张嘴清晰发声、其余同框角色闭嘴静态/抿嘴不语/未开口」**（例如：`@CHAR-01 张嘴清晰发声；@CHAR-02 僵立，闭嘴静态`），防止原生影音模型多人同时乱动嘴或串音。注：无对白的纯反应静音镜无需强加口型锁。
- **单镜人数与封闭管道**：单镜同框核心角色建议 **2–3 人（上限 4 人）**，全季常驻角色 **3–8 人**、主场景 4–6 处（单集 1–2 处、上限 3 处）；外部施压优先用“固定代表人物上门 + 纸质文书/道具 + 系统弹窗/电话画外音”消化，避免随手新增一次性露脸 NPC。
- **可选参考：严格帧锁批渲染产线（仅自动化渲染按需启用）**：仅当项目直连 `24fps` `17n+5` 帧锁批渲染管线时，可参考按需将对白数字写成纯汉字并微调句长对齐渲染档位（如 5s≈20字 / 7s≈28字 / 9.5s≈37字）；**常规剧本创作与人工/半自动生成严禁为了凑机械字数桶而硬剪或扭曲自然对白！**

### 2. 红果 `40×` 分成、零版权 BGM 与审稿安全线
- **红果 `40×` 分成生死线（旁白/OS ≤ 20%）**：冲红果最高 `40×` 分成系数的 AI 剧、漫剧与对白沙雕漫，必须以多角色现场口型对白推进，**单集旁白 + 心理独白（OS）字数占比严控 ≤ 20%（全季超标集数 < 3 集）**，防降档为 `10×` 动态解说漫剧（收益腰斩 4 倍）。注：画外角色对话（如 `画外陌生男声：“……”` / `@CHAR-01（画外）`）属于角色对白，不计入旁白 OS。
- **季播集数与时长**：AI 写实短剧常规 **30–60 集**（30 集 × 75–85 秒 ≈ 38–42 分钟，同时过红果 ≥20 分钟首传与 ≥30 分钟评奖线）；多季漫剧或长线爽剧可规划 **60–120 集**。
- **零版权 BGM（豁免剧情内自然声源）**：直投红果个人版权方时，避免额外叠加第三方版权背景配乐（BGM），主打“纯人声口型对白 + 精准物理 Foley 音效”（拍桌、碎瓷、盖章、油锅滋啦、卷帘门巨响）；**若剧情本身需要画面内自然声源/剧情必要音乐（如角色现场弹琴、收音机播老歌、KTV 对唱），属于画内实景声效而非外挂版权 BGM，照常合理描写，不机械封杀。**
- **审稿与生活质感**：去封建迷信（玄幻/规则类用“能量/算力/契约”等架空概念替代鬼神占卜）、零血腥暴力擦边；写年代、手艺、美食、职场题材时把真实物价、动作手艺与 Foley 底噪写扎实，让观众“下饭舒服”且爽点干脆不烧心。

### 3. `ai-drama` 标准单集剧本格式示例

```markdown
# 第001集 坏录像机

- 估测时长：75秒 ｜ 场景数：1（`@LOC-01`） ｜ 出场资产：`@CHAR-01` `@CHAR-02` `@PROP-01`
- 本集爽点/推进：开局3秒亮绝活破轻视，集末留黑市大佬登门钩子
（注：分集名用 2–6 字画面锚点或 4–8 字短钩子，推进摘要放上方字段，不塞进集名）

## 场 1｜日 · 内 · `@LOC-01` 城中村维修铺

**[镜01｜0-7s｜近景→特写｜`@CHAR-02` `@PROP-01`]**
- 画面：红姐双手叉腰堵在掉漆木门框里，手指戳着桌上外壳发黄的 `@PROP-01`，下巴微抬，张嘴清晰发声。
- 声音：[环境音] 巷口旧风扇咔哒响；`@CHAR-02`（泼辣快语速）：“八十五块租半个月？这破机子修不好，今晚你连被褥一起滚大街！”

**[镜02｜7-16s｜中近景｜`@CHAR-01` `@PROP-01`]**
- 画面：陈欢没抬头，拧开螺丝刀撬开后盖，镊子精准夹住发黑电容轻丢桌面，抬眼直视对方，张嘴清晰发声。
- 声音：[音效] 电容落桌清脆声；`@CHAR-01`（平稳带狠劲）：“三分钟，开机。”

...

**[集末卡点｜70-75s｜特写｜`@LOC-01` 门外]**
- 画面：刚亮起的雪花屏突然一暗，三双沾泥黑皮鞋踩碎门口水洼停在门槛前，一只夹烟的手拍上卷帘门。
- 声音：[音效] 铁皮门巨响；画外陌生男声（低沉）：“听说这儿来了个能修贴片机的神仙？”
- 【切黑屏，出下集预告】
```

## 剧种 2：`comic-drama`（2D / 3D 高奇观 AI 漫剧 · 默认后端 `jimeng` / `general`）

适配红果「漫剧」霸榜赛道（规则怪谈、末世倒计时/公路求生、玄幻修仙系统、无限流多季连载，常规划 **60–120 集/季**）：

1. **首集高燃开篇范式**：`0–20s` 先砸高质感世界异象/觉醒高光定格 → 切回当下瞬间爆发危机 + 肉眼可见的**极端数字劣势对比**（如旁人剩余 12 年，主角只剩 71 小时 59 分）→ 立刻抛出只有主角看懂的唯一破局变量 → 集末甩幕后视角或反转钩子。
2. **每集至少 1 个强视觉奇观锚点**：全息系统金光弹窗、头顶血条/倒计时、巨型锁链、异象裂变、战车变形等；将核心数值/规则写成屏幕可读的 **`[画面字幕/UI特效：...]`**。
3. **旁白/对白分轨控制**：上红果冲 `40×` 分成时把规则解释融进角色对话、系统播报与同伴吐槽，压低旁白/OS ≤ 20%；投抖音/推文引流可用快切冷峻旁白（每句 ≤20 字）并加 `--allow-high-narration`。
4. **动作场面省算力写法**：用 **`蓄力定格 + 冲击特写 + 结果全景`** 替代“连招三十回合翻腾踢打”（防 AI 动画畸变）。
5. **多季大地图扩展**：每 15–25 集换一次小副本，季末掀开更高维度真相或新强敌，支撑第 2/3 季连载。

## 剧种 3：`shadiao`（沙雕短剧 / 沙雕漫 · 默认后端 `general`）

立项时先定双子轨之一：

### 子轨 A：红果 `40×` 快切沙雕漫（竖屏 70–95 秒/集，15–40 集，旁白 ≤ 20%）
- **轻算力资产**：`PNG 核心主角（3–4 人）+ SVG 简约白人偶群演 + 固定切脸码（FACE-01 撇嘴冷笑 / FACE-02 鼻孔喷气 / FACE-03 死鱼眼 / FACE-04 下巴砸地等）+ HTML HUD 对比贴纸`，单集 1–2 个复用场景。
- **四段极速节拍（18–25 镜，2–4 秒/镜，口播约 320–400 字）**：
  1. `0–3s` 贴脸开局：踹门/当场羞辱 + 1 秒干脆反击，零铺垫；
  2. `4–30s` 嘴炮拉扯：高频一来一回反怼 + 规则/道具首次显灵（对手秒切真香脸）；
  3. `31–70s` 反转大打脸：卡在 99.9% 假危机 → 群演变脸闹剧 → 意外破局变量；
  4. `71–95s` 落袋强断章：黑白定格在冤种/反派呆滞脸上，一句俏皮补刀或悬念音切黑屏。
- **分成保卫**：主角吃瓜心声/旁白每集控制在 3–4 句以内（总字数 ≤20%），其余全用多角色口型对白推进。

### 子轨 B：抖音 / B 站 / 推文旁白沙雕动画（横/竖屏，2–15 分钟合集）
- 经典熊猫头/暴漫脸或 Q 版立绘 + 2D 平移切脸（首段可混剪 15–20 秒高燃画面拉完播）。
- 第一人称快嘴旁白 + 电话/场景对话交错，允许高旁白占比（体检传 `--allow-high-narration --compilation`）；用合规趣味谐音梗替代平台敏感词（如“丧坤”“狙鸡强”）。
- **两轨通用喜剧公式**：每 **10–15 秒** 一个「预期违背」包袱（一本正经铺常规套路 → 走向极度离谱但在本剧歪理里自洽的行动 → 音效骤停 + 毒舌神补刀），显式标 `[方言/1.2x快嘴/播音腔]`、`[HUD贴纸/花字]` 与 `[Foley/魔性音效]`。

## 单剧原声定调与去翻译腔红线（全剧种共用）

- **单剧声口切片**：在 `00_季播总案与资产表.md` 留存 150–250 字本剧最对味的试写台词+画面切片作为全季调音叉，防止连写多部剧全成同一种 AI 腔。
- **拒绝翻译腔与烂俗旁白套话**：台词与动作描写严禁出现“这不仅仅是一场……更是……”“空气仿佛凝固了”“命运的齿轮开始转动”“眼底闪过一丝……”等小说翻译腔（`lint_script.py` 会自动提示）；台词必须**念出来顺嘴、带活人气**。
- **保护正常口语与鲜活俚语**：不机械封杀自然口语词与生活化比喻，保留人物情绪爆点。
