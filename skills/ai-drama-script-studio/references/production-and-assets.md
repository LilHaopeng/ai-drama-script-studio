# 控算力资产圣经、肌肉导演法与视听体检交付规范

在 `bible`（建资产表）、`storyboard`（按需拆镜）、`check`（体检）与 `export`（导出交付）阶段读取。本文件为资产表上限、肌肉导演法、`lint_script.py` 体检维度与 `export_drama.py` 导出规则的**唯一权威来源**。

---

## 1. 控算力固定资产表（防崩脸与省抽卡命脉）

AI 短剧最大隐性成本来自剧本乱加人、乱换装、乱切新场景导致的抽卡浪费与崩脸。动笔前在 `00_季播总案与资产表.md` 锁定四大资产，全剧统一用 ID 引用：

| 资产前缀 | 管控上限（单季建议） | 必须锁定的视觉/声音锚点 |
|---|---|---|
| **`@CHAR-NN`**（核心角色） | 短期/沙雕 **3–5 人**；长线季播 **5–8 人**（总范围 3–8 人，其余作无脸背影或社会称呼路人） | 年龄、脸型气质、发型发色、**全季锁定标志穿搭**、标志小动作；命名遵守 [naming-and-titling.md](naming-and-titling.md) |
| **`@LOC-NN`**（复用主场景） | **4–6 个**核心场景（单集 **1–2 处**，上限 **3 处**） | 空间布局、时代/画风质感、固定主色调与光源，避免每集凭空生新场地 |
| **`@PROP-NN`**（核心道具/奇观） | **2–5 件**贯穿全季的关键物件 | 具象材质、发光或残缺细节（供特写转场与视觉记忆点，纯净导出自动还原为可读中文道具名） |
| **`@VOICE-NN`**（角色声线） | 与核心角色一一对应 | 音色性别年龄、语速倍率（写实 1.0x / 沙雕 1.15x–1.25x）、方言/口癖特征 |

### MiniMax-H3（Hailuo 3）多资产槽位守恒（`--backend minimax-h3`）
- 单次生成物理上限：**12 个参考元素（≤ 9 视觉图、≤ 3 视频、≤ 3 音频声线）**，单镜 **5–15 秒**。
- 实操稳态上限：单镜同框核心角色建议 **2–3 人（上限 4 人）**，单镜引用资产总数建议 ≤ 5 项，多人对峙改用“双人正反打 + 全景交代站位”。

## 2. 「肌肉导演法」：把心理描写 100% 翻译成可拍画面

视频模型无法理解抽象心理总结词。写 `[画面]` / `- 动作：` / `- 镜头：` 指令时，**只写摄像机拍得到、麦克风录得到的具体物理变化**：

| 不可拍的“小说心理腔” | 可直接生视频的「肌肉导演法」改写 |
|---|---|
| 他内心充满愤怒，暗自下定决心报复 | 画面：特写，他咬紧后槽牙，腮帮肌肉鼓起，右手死死攥皱合同纸，指节压出深折痕 |
| 她意识到自己被骗了，心中涌起寒意 | 画面：近景，她嘴角笑意突然僵住，瞳孔微颤，指尖停在手机拨号键上方发抖 |
| 众人震惊不已，空气仿佛凝固了 | 画面：中景切双人特写，端茶亲戚手一滑泼湿桌布，旁座两人同时停筷扭头；音效：茶杯磕桌脆响，环境嘈杂骤停 |
| 他早就看穿阴谋，不动声色 | 画面：特写，他垂眼轻滑手机，拇指点亮红色录音图标后平静扣在桌面 |

> 确实需要交代主角精准算计或吃瓜吐槽时，不要塞进 `[画面]`，改放进声音轨 **`@CHAR-01（OS/内心独白）：“……”`**（注意遵守目标平台旁白占比控制）。

## 4. 视听剧本与算力体检镜子（`lint_script.py`）

兼容 `[镜01｜0-7.5s]`、`[镜头01｜0-7s]`、`### 分镜01（5s）`、`### Shot 01 | 124帧 (5.17s)`、`### 【镜 01｜00:00–00:03】` 等主流产线写法：

```text
python <skill-dir>/scripts/lint_script.py --dir <项目根>/剧本 --genre <ai-drama|comic-drama|shadiao> --backend auto
```

- `--backend auto`（默认）：`ai-drama` 自动用 `minimax-h3`、`comic-drama` 自动用 `jimeng`、`shadiao` 自动用 `general`（绝不对沙雕短剧误报 MiniMax-H3 口型锁）；也可手动指定 `minimax-h3|jimeng|general`。
- 抖音/B 站旁白解说合集（2–15 分钟）可传 `--allow-high-narration --compilation`。
- 脚本始终作为客观镜子仅输出 `[ADVISORY]` 并返回退出码 `0`（仅路径/参数错误返回 `2`）。

### 体检维度速查

| 信号代码 | 体检内容 | 作用 |
|---|---|---|
| `hongguo_narration_over_20pct` / `season_hongguo_tier_drop_risk` | 单集旁白/OS/心声占比 > 20%（画外角色对白不误计为 OS）及全季 ≥3 集预警 | 守红果 `40×` 分成系数（见 [genre-templates.md](genre-templates.md)） |
| `minimax_missing_mouth_lock` | 仅 `minimax-h3` 下对**含口播对白且 ≥2 人同框**的镜头查口型锁定（静音反应镜不误报） | 防多角色同框串音或错误动嘴 |
| `minimax_shot_over_15s` / `minimax_too_many_assets` / `minimax_too_many_audio_assets` | 单镜 >15s、视觉资产 >9、总资产 >12 或音频声线槽位 >3 | 贴合 MiniMax-H3 物理槽位上限 |
| `below_platform_30s_floor` / `duration_too_short` / `duration_too_long` | 结合 `估测时长`/`总时长`/时间轴/镜数与语速估测单集时长 | 过红果 ≥30s 硬底线并守住各剧种时长区间 |
| `speech_line_too_long` | 单句对白过长（`ai-drama`/`comic-drama` >38 字；`shadiao` >46 字） | 防字幕挡脸与口型漂移 |
| `unfilmable_mental_direction` / `script_translationese_cliche` | 画面中不可拍心理词，及“这不仅仅是……更是……/空气仿佛凝固”等翻译腔套话 | 提醒改回肌肉导演法与自然活人口语 |
| `too_many_scenes` | 单集场景 > 2 处（建议 1–2 处，上限 3 处） | 控换场算力预算 |
| `missing_cliffhanger_hint` | 集尾未见卡点/强钩子提示 | 核查连播拉起力 |

## 5. 红果上传关键红线与双形态导出（`export_drama.py`）

- **红果上传核对**：剧名 ≤ 20 字符、禁 `《》<>【】[]` 与空格、禁夸张营销词（`爆款/绝密/最强/第一/逆天/秒杀/热播`）；单集 ≥ 30 秒，首传/双周激励 ≥ 20 分钟，终极评奖 ≥ 30 分钟；全剧简介 150–500 字，虚拟角色简介 10–100 字。
- `--root` 既可传项目根目录（自动查找 `剧本/`），也可直接传存放分集 `.md` 的剧本目录。
- `--format clean-script` 会自动读取 `00_季播总案与资产表.md` 将 `@CHAR`/`@LOC`/`@PROP`/`@VOICE` 及 `char_01`/`voice_char_01` 全部还原为可读中文名，彻底剥离 `[音效]`/`[环境音]` 技术描述，保留 `- 动作：`/`- 镜头：`/`[画面字幕]` 舞台提示，并拦截未填占位符。

```text
# 1. 产线执行版（保留完整镜号、资产ID、口型锁定、Foley音效与可选总案）
python <skill-dir>/scripts/export_drama.py \
  --root <项目根> \
  --out-docx <项目根>/交付/<剧名>_产线剧本.docx \
  --out-txt <项目根>/交付/<剧名>_产线纯文本.txt \
  --title <剧名> --format production --include-bible

# 2. 红果送审 / 编剧投稿纯净版（转为“第一集 / △动作 / 角色：台词 / （本集完）”）
python <skill-dir>/scripts/export_drama.py \
  --root <项目根> \
  --out-docx <项目根>/交付/<剧名>_送审纯净剧本.docx \
  --title <剧名> --format clean-script
```
